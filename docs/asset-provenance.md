# Asset provenance

Every pixel in the film is traceable to one of three sources.

## 1. Client photography — used as product, unaltered

| File | Used for |
| --- | --- |
| `assets/fabric/A-grid.png` | zigzag-jacquard swatches: `A-dark`, `A-grey`, `A-olive`, `A-beige`, `A-ivory`, `A-brown`; vertical macro `jacquard` (scene 2 plate) |
| `assets/fabric/B-chevron.png` | chevron swatches: `B-dark`, `B-grey`, `B-olive`, `B-beige`, `B-ivory`, `B-brown` |
| `assets/fabric/C-geometric.png` | basket-weave swatches: `C-dark`, `C-grey`, `C-olive`, `C-beige`, `C-ivory`, `C-brown`; vertical macro `geo` |
| `assets/fabric/D-ribbed.jpg` | corded twill: `D-brown`, `D-olive`, `D-tan`, `D-navy`; vertical macro `cord` |
| `assets/fabric/E-navyivory.jpg` | herringbone: `E-navy`, `E-ivory`, `E-beige`; vertical macro `herring` |
| `assets/fabric/F-fan.jpg` | 15 velvet swatches (`F-teal` … `F-wine`) used sparingly for colour range |
| `assets/logo/bahubali-logo.png` | the brand reveal and the end card |

Derivation for a swatch (see `src/assets.py`):

1. crop a face/interior region of the source (never across a cut edge, unless the cut
   edge is the point),
2. cover-crop to the plate aspect, optional slight rotation to follow the cloth,
3. build a pinked (zigzag) silhouette matching the real cutting blade,
4. add a thin cut-edge highlight biased to the key light direction,
5. bake a soft contact shadow into the plate.

No pattern is regenerated, no colour is replaced, no liquify or warp is applied to the
weave. Global grading is applied to the *scene*, not to individual swatches, and swatch
panels are additionally given a small per-panel light offset (`light=0.94±0.08`) so the
wall reads as photographed rather than pasted.

## 2. Generated plates — environment only

`assets/plates/scene1-desk.jpg`, `scene3-planning.jpg`, `scene4-rack.jpg`,
`scene5-studio.jpg`, `scene6-brand.jpg`, `scene7-endcard.jpg`.

These carry light, depth and material context. They are deliberately empty where type or
product lands, and no plate contains readable text, a brand mark or a product claim.

## 3. Code-generated graphics

Timelines, markers, rules, scrims, the gold sweep, the logo halo, the grain and the bloom
are drawn procedurally in `src/core.py` / `src/scenes.py`. No infographic is generated by
an image model, so no fabricated data can enter the frame.

## 4. Voice

Seven Hindi lines recorded with a single premium B2B voice, stored as
`assets/audio/vo-01…07.wav`, trimmed, EQ'd, compressed and de-essed in `src/audio.py`.
The script matches the approved copy in the brief; the Hinglish brand line was delivered
in Devanagari so the voice stays consistent.
